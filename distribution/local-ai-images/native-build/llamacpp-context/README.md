# Fixed llama.cpp native build context

The retained base, package databases, version locks and upstream identities feed the approved native x64 profile. The source-ready stage authenticates original packages, binds exact producer recipes and acquires complete sources before compilation. Compilation reuses that verified source image without network; runtime assembly uses the exact compiled image ID. Metadata and original vendor notices are retained. `../llamacpp-inputs.json` binds every context file; changes require a new context hash and full gate.
